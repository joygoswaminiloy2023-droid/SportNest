# 🏟️ SportNest - Client Side

## 📌 Project Name
SportNest - Sports Facility Booking Management System

---

## 🎯 Purpose
SportNest is a modern sports facility booking frontend built using **Next.js + React**.  
It allows users to explore sports facilities, book slots, manage bookings, and handle authentication securely.

---

## 🌐 Live URL
[https://your-live-site-url.com](https://sportnest-puce.vercel.app/)

---

## ✨ Features

- 🔐 User Authentication (Login / Register / Google Login)
- 🏟️ Browse Sports Facilities
- 📅 Book Facilities with Date & Time Slots
- 👤 User Dashboard (My Bookings, Add Facility, Manage Facilities)
- 🔎 Search & Filter Facilities
- 📱 Fully Responsive UI (Mobile / Tablet / Desktop)
- ⚡ Protected Routes (Private Pages)
- 🎨 Clean, Recruiter-Friendly UI Design
- 🔔 Toast Notifications for success & error messages
- 🧭 Dynamic Navigation based on login state
- ❌ Custom 404 Page
- ⏳ Loading Spinner for async data
